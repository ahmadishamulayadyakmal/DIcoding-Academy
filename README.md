# DIcoding Academy

Repository ini digunakan untuk mengumpulkan hasil pembelajaran dan proyek dari Program Studi Independen Bersertifikat Kampus Merdeka x Dicoding.

## Cakupan Pembelajaran

- Machine Learning
- Desain dan pengembangan website
- Final Project

## Struktur Repository

Revisi ke depan dapat mengikuti struktur berikut:

```text
machine-learning/
website-development/
final-project/
CONTRIBUTORS.md
README.md
```

## Memulai

```bash
git clone https://github.com/ahmadishamulayadyakmal/DIcoding-Academy.git
cd DIcoding-Academy
```
